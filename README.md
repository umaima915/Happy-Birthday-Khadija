# 🎂 Happy Birthday Khadija!

A personalized and interactive birthday surprise website created to celebrate a special friendship. 💗

This website is designed as a digital birthday gift, featuring animations, interactive surprises, heartfelt wishes and a scrapbook of memorable moments.

## 🌸 Features

- **Secret Passcode:** A personalized passcode screen to unlock the birthday surprise.
- **Animated Birthday Cake:** An interactive cake with candles that can be blown out.
- **Birthday Reveal:** A special birthday greeting with animated balloons.
- **Interactive Wishes:** Pop balloons to discover personalized friendship messages.
- **Urdu Wish Card:** A beautifully designed digital letter with a heartfelt birthday message.
- **Scratch to Reveal:** An interactive scratch card that reveals a hidden surprise.
- **Memory Scrapbook:** A digital scrapbook featuring pictures, dates and descriptions of special memories.
- **Animations & Effects:** Smooth transitions, floating elements and confetti effects.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, animations and responsive layouts
- JavaScript – Interactivity and functionality
- Canvas API – Scratch-to-reveal functionality
- Canvas Confetti – Celebration effects
- Google Fonts – Typography

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Happy-Birthday-Khadija.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Enter the correct passcode to unlock the surprise.

   **Note:** The default passcode in this project is `1511`.

## 🎨 Customization

You can personalize the website by:

- Replacing the birthday person's photo in the `assets` folder.
- Adding or replacing pictures inside `assets/memories/`.
- Updating memory dates, titles and descriptions in `js/memories.js`.
- Changing birthday wishes in `js/reveal.js`.
- Updating the secret passcode in `js/passcode.js`.
- Editing the birthday message in `index.html`.
